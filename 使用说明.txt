
────────────────────────────────────────────────────────────
  【关不掉 / exe 删不掉】（重要）
────────────────────────────────────────────────────────────

  现象：任务管理器里进程没了，但 SpaceHunter.exe 还提示「正在启动中」，
        删不掉也覆盖不了。

  这个程序已经加了**单实例保护**：不管你双击多少次快捷方式、
  从几个位置启动，都只会跑一个。第二个会被静默挡掉，
  并把已有那个的窗口叫到前面来（不会弹框挡你）。

  如果还是删不掉，按顺序试：

    1) 右键本目录下的「排障工具.ps1」→「以管理员身份运行」
       它会告诉你到底有几个进程、哪些是后台干活的提权子进程，
       然后全杀掉，并检查 exe 到底能不能访问。

       **一定要用管理员身份**。普通的权限杀不掉管理员进程 ——
       提权子进程是独立的进程，你把主窗口关掉它也不会跟着死。

    2) 等 30 秒再试。杀毒软件可能正在扫描这个 exe，
       扫描期间它会被独占占用。

    3) 关掉所有资源管理器窗口（可能正开着它的文件夹）、
       断开同步盘、断开远程桌面，再试。

    4) 最后手段：重启电脑。开机时程序还没运行，
       exe 一定是可删的。

  顺便说明一下「为什么会有后台进程」：
  删某些被系统保护的文件需要管理员权限，这时程序会弹 UAC，
  并**另起一个不显示窗口的后台进程**去干活。这个后台进程本身是正常的，
  但如果你在它干活的时候把主窗口强结束，它就会残留一段时间。
  现在它的最长工作时间被限制在 2 分钟以内，
  并且下次启动程序时会自动把上次的残留收掉。

────────────────────────────────────────────────────────────
  【空间地图为什么有时候什么都不显示】
────────────────────────────────────────────────────────────

  空间地图要逐个目录算体积，比较费 IO，所以**不会自动开跑**：

    · 第一次进这一页：显示「还没统计过，点下面的『统计这个盘』」
    · 点「统计这个盘」：目录名立刻出来，占用大小一个一个补上
    · 统计过的盘会记住结果，切来切去不再重算
    · 统计中随时可以按「取消」，已算出来的部分照样显示

【一句话】
  帮你找出 C 盘 / D 盘里的垃圾，看清楚之后再决定删不删。
  删掉的东西一律先进隔离区，你反悔了还能自己找回来。


【怎么开始】
  双击 SpaceHunter.exe 就行。别的什么都不用装。

  打开以后会自动扫一遍所有固定磁盘，几十秒到几分钟，
  取决于你盘里有多少文件。扫完左边会列出各类垃圾。

  想重扫：点右下角「重新扫描」，或者按 F5。


────────────────────────────────────────────────────────────
  【多个盘怎么看】
────────────────────────────────────────────────────────────

  开机会把**所有固定磁盘一次扫完**。之后：

  · 点左边任意一个磁盘的环形图 = 只切换「现在看哪个盘」
    右边立刻变成那个盘的清单。**不会重新扫盘**，就是过滤一下，
    所以你随便点、来回点都不会再读一遍硬盘。

  · 当前正在看的盘，环形图上有橙色描边。

  · 右上状态栏会写清楚两件事：
      「C:\ Windows　共 53 项 …」        ← 当前盘、当前盘的结果
      「三个盘一共扫到 995 项 / 186 GB」  ← 整轮扫描的总量

  · 空间地图页不一样：它要逐个目录算体积，比较费 IO，
    所以**只在你明确点「统计这个盘」时才做**，而且每个盘只做一次。
    点环形图切到别的盘再切回来，直接显示上次的结果，不会重算。

────────────────────────────────────────────────────────────
  【扫描中途想停】
────────────────────────────────────────────────────────────

  进度窗上的「取消」是真的会停的，一般 2～4 秒内就停下
  （最慢的情况是正在算一个超大目录的体积，会多等一会儿）。

  停下来之后：
    · 已经扫到的那部分**保留下来，照样能用**
    · 状态栏会标「中途停止过，结果不完整」
    · 也会弹一次提示，说明这份结果不完整、没扫到的不会出现在清单里

  想要完整结果，再点一次「重新扫描」。

────────────────────────────────────────────────────────────
  【鼠标滚轮坏了 / 没有滚轮，怎么翻列表】
────────────────────────────────────────────────────────────

  程序里每个清单的右边都画了一条竖滚动条，三种用法：

    · 上下两个三角   点一下翻一页
    · 中间那根滑块   按住上下拖
    · 滑块外的空白   点一下翻一页

  还可以用键盘：先用鼠标点一下列表，然后按

    ↑  ↓          上下移动一行
    PgUp  PgDn     上下翻一页
    Home  End      直接跳到最上面 / 最下面

  走过的行会有一条橙色竖线，你永远知道自己在哪儿。


────────────────────────────────────────────────────────────
  【左侧那一列：分类】
────────────────────────────────────────────────────────────

  每一类右边有个方框，勾上表示「这一类我打算清」。

  · 上面「全部」那一行：点一下是全选 / 全不选
  · 右边一排标签：点哪个，右边就只看哪一类
    （看某一类跟这里的勾选互不影响 —— 你能看不能选）

  勾选只决定「清理所选」会动哪些，不影响你能看到什么。


────────────────────────────────────────────────────────────
  【清理是怎么工作的】
────────────────────────────────────────────────────────────

  点「清理所选」之后：

  1. 每一项先做一次真的「改名 → 改回」的试探
     —— 这一步就决定了它是进隔离区还是直接删。
       能改名的      → 移到隔离区（后悔了可以自己搬回去）
       改不了名的    → 直接删掉（通常是正在被占用的）

  2. 删不掉的会走一条更狠的路：先摘掉目录上的保护性权限，再删。
     程序用的是 Windows 自带的 icacls，不是自己写的。

  3. 还是不行、并且程序不是管理员身份运行的，会弹一次 UAC 问你要不要用
     管理员权限再试一次。你点「否」没关系，那几项就留在原地，不会乱删。

     提权那一步是**一个不显示任何窗口的子进程**：
     它不弹界面、不扫盘，干完活立刻退出（通常 1～2 秒）。
     如果超过 10 分钟还没结束，程序会把它停掉并告诉你，
     不会让你对着一个不动的界面干等。

  4. 全部删完后会弹一个结果告诉你成功多少、失败多少，
     以及**具体是哪几项失败、为什么失败**。

  隔离区在：
    %LOCALAPPDATA%\SpaceHunter\隔离区

  里面按「盘符 + 原路径」原样存放，比如
    隔离区\D\Users\你\Downloads\xxx.exe
  你能一眼看出它原来在哪，想搬回去就是复制回去。

  清空隔离区：左下角「隔离区」→ 确认。
  这个操作撤不回来，所以确认框是红色的。
  超过 30 天的隔离内容在下次启动时会自动清掉。


────────────────────────────────────────────────────────────
  【排除：不想被碰的路径】
────────────────────────────────────────────────────────────

  在右边清单里右键某一项 → 确定，就把它永久排除了。

  排除清单在：
    %LOCALAPPDATA%\SpaceHunter\exclude.txt
  一行一个路径，可以用记事本直接改。

  左下角「排除项」可以看到当前排除了哪些。


────────────────────────────────────────────────────────────
  【空间地图】
────────────────────────────────────────────────────────────

  点进去之后需要点一下「统计这个盘」才开始统计 —— 这样你只是路过看看的时候，
  不会莫名其妙触发一次全盘遍历。

  统计是渐进的：目录名立刻就出来，占用大小在后台一个一个补上，
  所以不用盯着空白屏幕等。统计过一次就记住了，再切回来不会重算。

  统计过程中点「取消」同样能停下来（已统计出来的部分照样显示）。

  双击某一行可以直接用资源管理器打开那个文件夹。


────────────────────────────────────────────────────────────
  【软件卸载】
────────────────────────────────────────────────────────────

  点「软件卸载」标签。注意：**刚打开时是空的**，
  这是故意的 —— 得先扫，扫完才有清单。

  点「扫描已安装软件」，程序会同时看三个地方：

    1. 注册表  —— 只有这里有真正的「卸载命令」
    2. 磁盘上的程序目录（Program Files、%LOCALAPPDATA%\Programs…）
                —— 能发现绿色软件、或者注册表坏掉的
    3. 桌面和开始菜单的快捷方式 —— 能发现装在奇怪位置的

  右边那一列写着每个软件的来源：

    可卸载   有官方卸载命令，可以直接卸
    仅目录   只知道它装在哪，得去它自己的界面里卸
    快捷方式 从快捷方式反查到的，多半是绿色软件

  勾选要卸的，点「卸载所选」：
    · 有卸载命令的，会调用它官方的卸载程序
      （优先静默参数；不支持静默的会弹它自己的界面，
        那种情况需要你到那个窗口里点确认）
    · 没有卸载命令的，程序只会告诉你装在哪，不会乱动

  卸载完会逐个核对残留，勾中的残留同样先进隔离区。


────────────────────────────────────────────────────────────
  【关于你的硬盘】
────────────────────────────────────────────────────────────

  · 只扫固定磁盘（本地硬盘）。移动硬盘不扫。
  · 只有一两个盘完全没问题，界面会按实际盘数排布。
  · 不写盘根目录。隔离区永远在 %LOCALAPPDATA% 下，
    所以在「盘根目录不能建文件夹」的机器上也能正常工作。
  · 程序本身不联网、不上传、不写注册表（只读注册表）。
  · 不会碰：
      - 系统目录（Windows、Program Files、回收站本体等）
      - 半年内还在变动的 AppData 目录
      - 排除清单里的路径
      - 同名不同位置的「重复文件」里较新的那份（保留最早的一份）
      - **任何链接点**（junction / 符号链接 / 云盘占位符）

    最后这条要特别说明一下，因为踩过狠的：
      C:\Users\All Users 其实是指向 C:\ProgramData 的 junction。
      早期版本顺着它走进 ProgramData，然后把
      C:\ProgramData\Microsoft\Windows Defender\Support 整个搬进了隔离区。
      系统目录被隔离区程序搬走是要出事的。

    现在有三道闸：扫描不进链接、清单收录前再查一次、
    真正动文件之前最后拦一次。路径里只要有链接，一律跳过不动。


────────────────────────────────────────────────────────────
  【清理时遇到删不掉的】
────────────────────────────────────────────────────────────

  清理过程中如果某一项卡住了：进度窗一直在显示当前在处理第几项、
  是哪一项，不会像以前那样一动不动。

  一段处理完之后会列出**具体哪几项没成功、是什么原因**（只列前 8 项）。
  绝大多数是「正被占用」—— 关掉对应程序，或者重启一次再清就干净了。

  还有一种情况是目录带着系统级的保护权限（Deny 规则把自己也禁了），
  这种连读它的权限设置都读不到，**非管理员怎么试都没用**。
  这种情况程序会弹一次 UAC 问你「要不要用管理员权限再试一次」：
    · 你点「确定」→ 它会先夺回所有权、授予管理员权限，再删
    · 你点「取消」→ 那几项原样留在原地，不会乱动

  想清空隔离区也是同样的逻辑：遇到清不掉的会自动请求提权。
  万一还剩一点，程序会如实告诉你剩多少，不会假装清干净了。



────────────────────────────────────────────────────────────
  【杀毒软件可能误报】
────────────────────────────────────────────────────────────

  这个程序会枚举进程、读注册表、请求管理员权限、
  递归删文件 —— 这几件事凑在一起，正好是启发式引擎
  最爱报警的组合。

  如果卡巴斯基 / 360 / Windows Defender 拦它：
    1. 先确认文件没被删（多半只是被隔离了）
    2. 把 SpaceHunter.exe 加进信任区
    3. 或者右键 → 属性 → 勾上「解除锁定」→ 确定

  出现崩溃时可以看日志：
    %LOCALAPPDATA%\SpaceHunter\崩溃日志.txt


────────────────────────────────────────────────────────────
  【给自己改代码 / 重新编译】
────────────────────────────────────────────────────────────

  源码在 src\ 下，一共 8 个文件，编号就是依赖顺序：

    1_Theme.cs      配色、字体、格式化、绘图小工具
    2_Model.cs      分类定义、扫描结果、可移动性预检查
    3_Quarantine.cs 隔离区（移动/删除/权限）、UAC 提权
    4_Controls.cs   滚动列表基类、按钮、环形图、进度窗
    5_Lists.cs      五个清单控件（垃圾/地图/分类/软件/残留）
    6_Apps.cs       软件扫描、卸载、卸载残留查找
    7_Scan.cs       垃圾扫描引擎
    8_Main.cs       主界面 + 入口

  重新编译：双击「重新编译.bat」
  （只用 Windows 自带的编译器，不需要装 Visual Studio）

  跑一遍核心逻辑的自检：右键「运行自检.ps1」
  自检只在临时目录里造测试数据，不会碰你的任何文件。


────────────────────────────────────────────────────────────
  【几个调试用的隐藏参数】（平时别用）
────────────────────────────────────────────────────────────

  SpaceHunter.exe --noscan          启动时不自动扫描
  SpaceHunter.exe --drives=1         只显示 1 个盘（模拟单盘机器）
  SpaceHunter.exe --only=关键字       只列出路径含「关键字」的项
                                   （用来在真实数据上安全地试清理流程）
