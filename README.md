## 为什么做这个

清理类的工具大多有两个毛病：

- **删了就没了** —— 出了问题找不回来
- **不动脑子就敢删** —— 把系统目录、正在用的文件一并带走

这个程序的做法：

1. 删的一律先**移到隔离区**，不真删。隔离区按「盘符 + 原路径」原样存放，你一眼能看出它原来在哪
2. 每一项在动手前先做一次真的「改名 → 改回」试探，**能不能搬得动当场就知道**，不靠猜
3. 系统目录、链接点（junction / 符号链接）、隔离区自己，全部三重拦截

## 使用

下载 [`SpaceHunter.exe`](https://github.com/benkeshengkk/SpaceHunter/releases/latest)，双击。

第一次开机会自动扫一遍所有固定磁盘，几十秒到几分钟不等（取决于盘里有多少文件）。

界面上的操作：

- **左上环形图** —— 点一下切换现在看哪个盘（当前盘有橙色描边）
- **右上标签** —— 垃圾清单 / 空间地图 / 软件卸载
- **左侧分类** —— 勾选决定「清理所选」会动哪些；点右上某个分类标签则只看那一类
- **清单行** —— 左键点行选中，右键排除该路径
- **底部** —— 清理所选 / 重新扫描
- **F5** 重新扫描　**F1** 关于

### 清理是怎么工作的

1. 每项先做一次真的「改名 → 改回」
   - 能改名的 → 移到隔离区（后悔了可以自己搬回去）
   - 改不了的 → 直接删（通常是正在被占用）
2. 删不掉的先摘掉保护性权限再删（用 Windows 自带的 `icacls`）
3. 还不行、且程序不是管理员身份的，弹一次 UAC 问你要不要提权再试
   - 提权那步是一个**不显示任何窗口的后台进程**，干完立刻退出（通常 1～2 秒）
4. 结束后告诉你成功多少、失败多少，以及**具体是哪几项失败、为什么**

隔离区位置：

```
%LOCALAPPDATA%\SpaceHunter\隔离区
```

里面按「盘符 + 原路径」原样存放，比如：

```
隔离区\D\Users\你\Downloads\xxx.exe
```

### 哪些东西一定不碰

- 系统目录（Windows、Program Files、ProgramData、Boot、Recovery、回收站本体…）
  —— **所有固定盘**都保护，不只 C 盘
- 任何链接点（junction / 符号链接 / 云盘占位符）
  —— `C:\Users\All Users` 是指向 `C:\ProgramData` 的 junction，跟着它走会把系统目录搬走
- 隔离区自己（防止把自己的备份当垃圾清掉）
- 半年内还在变动的 AppData 目录
- 排除清单里的路径

源码在 `src/`，8 个文件，编号即依赖顺序。

**不需要** Visual Studio，不需要 NuGet。Windows 自带的编译器就够：

```powershell
.\build.ps1
```

或者直接双击 `重新编译.bat`。

### 跑自检

```powershell
.\运行自检.ps1
```

会在临时目录里造测试数据，验证隔离区、移动、跨盘复制、ACL 处理、参数约定、
系统目录拦截、隔离区自我保护等核心逻辑（103 项）。**不会碰你的任何文件。**

### 遇到关不掉 / exe 删不掉

```powershell
# 右键 → 以管理员身份运行
.\排障工具.ps1
```

它会列出所有实例（区分正常实例和后台提权子进程）、全部结束，
并实测 exe 到底能不能访问。

常见原因：重复启动（已加单实例保护）、杀毒软件正在扫描、
资源管理器开着它的文件夹、同步盘正在传它、管理员进程需要管理员权限才能杀。

## 开发者备注

### 几处踩过的坑（都在代码注释里写明了原因）

- **`quarantine.Root` 必须在 `%LOCALAPPDATA%` 下**，不能用盘根目录 ——
  非管理员在 `D:\` 根目录连文件夹都建不出来，那样整盘任务会直接失败
- **清空隔离区绝不能用 `icacls /T`** —— 单次曾要 120 秒 × 4 个 SID，
  一个上万文件的目录能卡好几分钟。逐个对象处理才是毫秒级
- **跨盘复制不能用 `Microsoft.VisualBasic.FileSystem`** ——
  它内部走 COM，而清理跑在线程池的 MTA 线程上，会直接把进程打崩
- **长度相同的路径必须比内容** —— `C:\System Volume Information` 和某个用户的
  `\AppData\Roaming` 都是 28 字符，只比长度就会误伤用户的目录
- **提权子进程的参数个数要和判断严格对齐** —— 少判一个就会开出完整主界面并自动扫盘

### 架构

```
1_Theme.cs      配色 / 字体 / 格式化 / 绘图工具 / 控件树遍历
2_Model.cs      分类定义 / 扫描结果 / 可移动性预检查
3_Quarantine.cs 隔离区（移动、删除、权限）/ UAC 提权 / 单实例残留回收
4_Controls.cs   ScrollList 基类 / 按钮 / 环形图 / 进度窗
5_Lists.cs      五个清单控件（垃圾 / 地图 / 分类 / 软件 / 残留）
6_Apps.cs       软件扫描 / 卸载 / 卸载残留查找
7_Scan.cs       垃圾扫描引擎 / 链接点与系统目录拦截
8_Main.cs       主界面 / 布局 / 入口
```

所有列表共用 `ScrollList` 基类，它负责滚动条、键盘导航、
以及把选中行自动滚进可视区。
